# Solar-Powered Drone for Agricultural Automation

## Overview

This repository documents my B.Tech Electrical and Electronics Engineering project investigating the use of a solar-powered drone for agricultural automation.

The project explored the application of electrical engineering, renewable energy and automation concepts to agricultural operations.

## Problem Context

Agricultural operations can benefit from automated aerial systems for tasks such as crop monitoring, field observation and agricultural data collection.

The project investigated how a drone platform could be combined with solar energy and electrical systems to support agricultural applications.

The project aimed to investigate:
